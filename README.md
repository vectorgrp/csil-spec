# CSIL Node Packaging Specification

This repository holds the text of the CSIL Node Packaging Specification and its backend profiles in [`spec/`](spec/).
The specification is also published as [HTML](https://vectorgrp.github.io/csil-spec/).

- [`spec/SPEC.md`](spec/SPEC.md): main specification document (entrypoint)
- [`spec/FOLDER.md`](spec/FOLDER.md): folder backend profile
- [`spec/OCI.md`](spec/OCI.md): OCI backend profile
