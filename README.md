# CSIL Node Packaging Specification

This repository holds the text of the CSIL Node Packaging Specification and its backend profiles in [`spec/`](spec/).
The specification is also published as [HTML](https://vectorgrp.github.io/csil-spec/).

- [`spec/SPEC.md`](spec/SPEC.md) ([HTML](https://vectorgrp.github.io/csil-spec/spec/SPEC.html)): main specification document (entrypoint)
- [`spec/FOLDER.md`](spec/FOLDER.md) ([HTML](https://vectorgrp.github.io/csil-spec/spec/FOLDER.html)): folder backend profile
- [`spec/OCI.md`](spec/OCI.md) ([HTML](https://vectorgrp.github.io/csil-spec/spec/OCI.html)): OCI backend profile
